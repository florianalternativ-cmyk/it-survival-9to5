# Mobile V4 in einem neuen GitHub-Repository testen

1. ZIP entpacken.
2. Auf GitHub **New repository** wählen und ein leeres Test-Repository erstellen.
3. Alle entpackten Dateien direkt hochladen. `index.html` muss im Root liegen; `.github/workflows/deploy-pages.yml` muss erhalten bleiben.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions** auswählen.
5. Unter **Actions** den Workflow „Deploy IT-SURVIVAL to GitHub Pages“ abwarten.
6. Die veröffentlichte URL öffnen.

Die alte Repository-Version wird dabei nicht verändert.

## Alternative

Settings → Pages → **Deploy from a branch** → `main` → `/(root)`.

## V4 erkennen

- Emojis sind wieder in moderater Menge sichtbar.
- Kaffee sinkt alle 4 Sekunden.
- HDMI und USB besitzen keine Dreh-Schaltfläche.
- Die Stecker werden direkt gezogen.
- Beim HDMI-Ziehen scrollt die Werkbank am Bildschirmrand automatisch.

Bei einer alten Ansicht die URL einmal mit `?v=mobile-v4` öffnen.
